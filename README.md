# ATX-Bench-Power-Supply

A DIY, Bench ATX power supply

## Features

- Custom Voltage & Amperage
- 4x Defaults voltagem plugs (3.3v, 5v, 2x 12v)
- 4x Banana Plugs for GND
- 4x Banana Plugs for Volts
- 1x Custom voltage 1,25v to 12v
- 1x P4 plug (12v)

## Status

- In development

## Based On

- [ATX Bench Power Supply Enclosure by Nozzle1](https://makerworld.com/en/models/3002094-atx-bench-power-supply-enclosure#profileId-3370680)

## Materials

- 8x Banana plugs, RED and Black
- 1x Borne P4
- 2x Linear Potentiometer 10K
- 1x Step Down Voltage Converter Module 300W 8A XL4016 Adjustable Voltage and Current
- 1x Voltmeter and Ammeter Display 0 to 100V 10A
- 1x Seesaw Key KCD1-101 2 Terminals Red
- 1x Old ATX power supply
- 4x Heat-Set Insert M3 x 5.7 x 4.2mm
- 4x M3 Screws

## Tools Used

- Fusion 360
- OrcaSlicer
- Equipment for basic electronics
